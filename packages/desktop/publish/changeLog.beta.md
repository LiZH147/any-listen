### Improved

- The main window can now be resized by dragging its edges or corners, and the size you adjust is remembered and restored on the next launch.

### Fixed

- Fixed an issue where using the keyboard shortcut to open Search unexpectedly activated list multi-selection mode.

### Changed

- Desktop lyrics now use **Multi-line Lyrics** mode by default.

---

<!--- @lang: zh-cn -->

### 优化

- 主窗口现在可以通过拖拽边缘或边角调整大小，调整后的尺寸会被记住并在下次启动时恢复。

### 修复

- 修复使用快捷键打开搜索时意外进入列表多选模式的问题。

### 变更

- 桌面歌词默认使用 **「多行歌词」** 模式。
